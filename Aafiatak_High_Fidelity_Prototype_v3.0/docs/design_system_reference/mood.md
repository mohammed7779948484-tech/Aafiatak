# Aafiatak Brand Mood — Quiet Vitality

> **v2.1 palette update:** the product now runs the *Burgundy Monochrome* system — three source colors only:
> `#800020` (brand burgundy), `#FFFFFF` (base), `#E5E5E5` (sub neutral). All status colors (green/orange/blue/red)
> were removed; positive states use the burgundy, caution/critical states use charcoal, and meaning is carried by
> icon glyphs and copy. The "Mineral Bloom" multi-hue notes below are retained as historical reference for v1.x only.

## Personality keywords

1. **Reassuring** — calm before clever.
2. **Precise** — health, payment, and queue truth never feel vague.
3. **Human** — warm without becoming playful or childish.
4. **Quietly premium** — quality through restraint, alignment, typography, and materials rather than decorative excess.
5. **Contemporary Arabic** — RTL-native, culturally comfortable, globally fluent.

## Visual direction

- Mineral Bloom palette: Damson + Sea Glass + Copper Blush + warm Porcelain neutrals.
- Surface-led hierarchy with restrained elevation.
- Soft geometric forms, especially the Care Window arch motif.
- Generous but efficient whitespace.
- Rounded geometry with discipline; avoid excessive pill shapes.
- One dominant action per task view.

## Do

- Use Damson as the visual anchor.
- Let Porcelain and Ivory dominate large surfaces.
- Use Sea Glass for restorative/supportive context.
- Use Copper Blush for human warmth and hold/time-attention patterns.
- Preserve strong semantic colors for actual status.

## Don't

- Generic hospital-blue-only palette.
- Purple/blue AI gradients.
- Glassmorphism-heavy surfaces.
- Literal medical cross, heart, ECG, or stethoscope as decorative identity.
- Neon health-tech styling.
- Oversaturated status colors.
- Multiple competing primary buttons.
